Can apprixmate a function using: $f(x ; \boldsymbol{\theta})=\sum_{i=1}^m w_i B_i(x)$
- where $B_i$ is the ith basis function

Splines
- A spline is a piecewise polynomial of degree $D$
	- location are set by knots, $t_1, ..., <t_m$
	- Cubic Splines: $D=3$
	- Can convert a Data matrix $X$ to a $N \times (K+D-1$ ) matrix $B$ where K is the number of knots and D is the degree

![[Splines.png]]
First Row is unweighted and second row is weighted where each column is $D=0,1,3$
- only $D+1$ basis functions will be active at any point $x$

Fitting a linear model using a spline
- Compute design matrix $B$ then fit a linear model using least squares or ridge regression
- Rewrite the spline as: $\begin{gathered}f(x)=\beta_0+\beta_1 x+\beta_2 x^2+\beta_3 x^3+\sum_{k=1}^K \gamma_k\left(x-\xi_k\right)_{+}^3 \\ \left(x-\xi_k\right)_{+}^3= \begin{cases}\left(x-\xi_k\right)^3 & x>\xi_k \\ 0 & x \leq \xi_k\end{cases} \end{gathered}$

Smoothing Splines
- use $N$ knows where N is the number of datapoints
	- Non Parametric Model
	- Smoothing splines rely on l2 regularization

#### GAM Model

Generalize Additive Mode or GAM
- Extends spline regression to case of multidimensional inputs
- $f(\boldsymbol{x} ; \boldsymbol{\theta})=\alpha+\sum_{d=1}^D f_d\left(x_d\right)$
	- $f_d$ : regression or smoothing spline
	- Fit using Backfitting
		- iteratively fits each $f_d$ to the partial residuals generated by other terms
